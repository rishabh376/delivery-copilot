# FAQ - delivery-copilot

**Q: What problem does this actually solve?**
A: Helps devops teams reduce toil around delivery with a guided workflow and measurable guardrails.

Pain point: Teams still fight slow manual work, unclear ownership, and brittle handoffs when delivery is under pressure.

**Q: Free to run?**
A: Yep. Cloudflare - $0/mo. See `terraform/INFRA_REQUIREMENTS.md`

**Q: Production ready?**
A: Yes - SLOs, security hardening, DR runbook, Helm, Terraform, monitoring.

**Q: Stack?**
A: Go, Argo Rollouts, Crossplane, Terraform, Vault, OTel, Prometheus, Multi-cluster

**Q: What infra do I need?**
A: `terraform/INFRA_REQUIREMENTS.md` has the full breakdown - CPU/RAM/storage/network/cost.
